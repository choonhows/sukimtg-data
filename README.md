# SukiMTG data

Files the SukiMTG app downloads in the background: an offline card catalogue and daily prices, published nightly as assets of the `catalogue` release. Data only, no code.

Card data from [Scryfall](https://scryfall.com); prices from TCGplayer via [tcgcsv](https://tcgcsv.com). Not affiliated with Wizards of the Coast.
